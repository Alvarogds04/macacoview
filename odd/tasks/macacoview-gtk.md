# MacacoView GTK: implement design 07 in the GNOME app

Implements `design/macacoview/07-cabina-combinada-animada.html` (the live spec; 06 is its static
version) in `gui/pc_ai_monitor/` on branch `feat/macacoview-design`, on top of main `b1b66af`.
Missing updaters for models, router and tools are a separate backend task in `pc-ai-local-models`.

## Specs

- S1 «Implement it in the project's real stack. Use the artboard as the visual spec: map its parts to the project's existing components and styles, and do not copy the artboard HTML verbatim.»
- S2 Visible name «MacacoView» in window, headerbar and title; identifiers unchanged (`APP_ID local.pcai.monitor.gnome`, `pc-ai-monitor` paths, service, extension id) — «Nombre visible ahora, identificadores después».
- S3 «Todo este apartado que sea de motores y lo de arriba que sea Home»: a new **Home** page (first sidebar row, default at launch) with the cockpit — RAM blocks + 15-min motor band + compact switch with two mini engine cards; decode/prefill lanes with shared cursor + cache/KV rings, MTP dial, GPU lamp, request dots; inventory + RAM headroom + one-state update card. **Motores** holds the detail blocks.
- S4 «Este boton que sea mucho mas pequeño» / «No dejes este espacio vacio ajustalo al diseñ, pero sin hacer el cambiar abito tan grande»: compact «Cambiar a …» button (Ctrl E) under two mini engine cards.
- S5 «esto que no diga el commit si no la version o otra cosa que sea mas visual»: versions shown as human versions (`version_label` / `available.latest`) with a status pill (Todo al día / N actualizaciones / Revertida / Actualizando… / No se pudo consultar); tags and revisions only in tooltips.
- S6 «ESto que solo diga si es necesario actualizar y ya, y que modelos motores y eso se pueden actualizar de todos loque estan en el pc»: Home update card = one state + one button; Motores «Actualizaciones del PC» lists every updatable component with version, status pill and «Actualizar», plus «Actualizar todo (N)». Decision (L5): add the missing updaters (separate backend task B1); the UI uses them when the backend reports them and shows «sin actualizador todavía» otherwise.
- S7 «Esto lo prefiero mas visual que en texto»: Motores performance as instruments (lamps, rings, bars, sparklines, dial); sentences in tooltips; warning/error as coloured banners; manual «Actualizar» kept.
- S8 «actrualicemos todo lo de router por lo nuevo de los modelos actualesy todo lo actual y que esto se actualice solo y menos texto y mas visual , con filtros charts y todo»: Router rebuilt on the current engines and real `/status` + `/metrics` fields: KPI strip, routes-over-time chart, per-engine cards, decisions stream with filters (ruta, decisor, ventana 5/15/60 min, búsqueda) that filter rows and chart, confirmations with countdown, lifecycle timeline, JEV/CLOUD/ENGRAM tiles, sessions; live refresh; «router no responde en :11009» state.
- S9 Gufo RAM «los 2»: show «≈ 85 GiB reservados» and «49.2 GiB en uso» (measured); Abito «≈ 20 GiB» / measured. Switch load times from the source (Gufo ~90 s, Abito ~30 s).
- S10 «con todos los elementos actuales que tiene pc-monitor … y con todas sus funcionalidades»: every element and function in `design/macacoview/INVENTARIO-APP.md` keeps working (group/model drill-down, provider filter, port filter and sorts, process sorts, Configuración rows, themes, Monitoreo).
- S11 Data honesty (L2): metrics only from `/metrics`, `/v1/models`, `/slots`, `gufo-flash status`; prefill/decode derived from counter deltas, «sin datos recientes» never 0; no TTFT, no GPU temperature; rollback only on health, context mismatch or pull failure.
- S13 «vamos a la version nueva» + «Integrar primero el selector de RAM»: the installed app becomes this branch's version without losing the RAM program selector deployed on 10-05 (uncommitted work in `worktrees/ram-program-selector`).
- S12 Text level: «creo que me he pasado con lo de 85 asi que lo podemos dejar a un % mas razonable» → about 60 % less visible text than direction 01, labels and units kept.

- S14 «cuando le de a un boton de actualizar,encender o hacer una accion que requiera tiempo tenga una loading bar de cuanto seria el progreso»: every long action (update, start/stop a model, switch engine) shows inline progress in the card that started it plus a compact global indicator in the header, following `design/macacoview-hoy-vs-08/08-acciones-con-progreso.html` tab 1. A % is shown only when a real number exists (cmake «[ NN%]» while compiling llama.cpp); otherwise stage N/M when the stage is observable, else an indeterminate bar with elapsed time and the typical duration. Success and error states (with the reason, «Reintentar», «Ver detalle»); no «Cancelar» (L28).
- S15 «que en home haya un boton de activas y desactivar los modelos locales»: Home gets a master «Modelos locales» switch and one switch per engine (Abito, Gufo), per 08 tab 2. Only one resident engine: turning one on while the other runs asks for the switch confirmation. Master on = start Abito; master off = stop the running engine (L28). Transitions use the S14 progress.
- S16 «los botones de motores no parecen que funcionen»: root cause fixed in 8d3eccf (GTK 4 dialogs); additionally every disabled button in Motores states its reason inline under it, not only in a tooltip, per 08 tab 3.
- S17 «en recursos en pi es posible que me diga el nombre de cada sesion y lo que ocupa en memoria?»: Recursos → Pi lists one row per Pi session: name (`session_info.name` from the session JSONL, else cwd basename + short session id), PIDs, PSS as the main figure, RSS secondary, children; subagent sessions nested under their parent session; PSS never added to the group RSS («no sumar»), per 08 tab 4.
- S18 Secondary text contrast: muted text uses `#8394A3` (≥4.5:1 on graphite) instead of `#5C6170`, as in 08 (L28).

- S19 «pero sigue estando la lista super larga» / «es que calro no tengo ni idea que son todos estos podemos definorlo de una menera diferente y mas comoda para el CX?»: Configuración's «RAM por programa» no longer lists every discovered program. It shows the «Mostrar programas seleccionados» switch, the pinned programs (name, live memory, «Quitar») with an empty state, and «Agregar programa…» opening a dialog with a search box and the 15 largest by RAM, system/unreadable and < 50 MiB hidden behind «Incluir procesos del sistema y los chicos», per `design/macacoview-app/10-ram-por-programa-propuesta.html` section B/C (L34).

- S20 «arreglalo, dale, dale» (accepting the recommendation after L39): fix the non-blocking native-review findings of the Pi sessions collector (PI_SESSION_FILE taken from a child environ is not trusted as a path; pi roots filtered to the current user; the environ high-confidence mapping and datos.py:316-321 covered) and of the long-command runner (e4681c4: motores.py streaming runner, actualizaciones.py:331-367, motores.py:304-305, app.py:446, home.py:282-302), each with a test that fails first. Readability findings of 72e616f/aaa753d/8d3eccf and the fe23680 findings stay for later (L40).

- S21 «veo que no existe un boton de parar cuando estan cargando un modelo, esposible añadirlo?»: while a model is loading (Encender Abito = `ensure abito`; Encender/Cambiar a Gufo = `switch gufo`), the inline progress shows a «Detener» button with a confirmation. Detener ends the running command and leaves no engine loaded: Abito → `local-ai-models stop abito`; Gufo → `gufo-flash stop --no-restore`. The activity ends as «Detenido» (not an error), the switches reflect the real state afterwards, and the header indicator clears. Updates (compile) never offer Detener (L42).
